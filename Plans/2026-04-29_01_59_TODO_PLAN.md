# Implementation Plan: Add Login Option to Frontend and Backend

**Created:** 2026-04-29 01:59
**Status:** Completed

## Overview
Implement user authentication with username/password, associate jobs/processes with users for filtering, and add API key/model selection capabilities while maintaining existing functionality.

---

## Phase 1: Backend Authentication Infrastructure

- [ ] **1. Setup Backend Authentication Infrastructure** (Complexity: 3)
  - Install and configure Django REST Framework's JWT authentication package (djangorestframework-simplejwt)
  - Update settings.py to include rest_framework_simplejwt in INSTALLED_APPS
  - Configure authentication classes and permissions for API
  - Set up JWT token settings (access token lifetime, refresh token lifetime)

- [ ] **2. Create User Model Extensions** (Complexity: 5)
  - Create UserProfile model with fields:
    - user (OneToOneField to User)
    - openrouter_api_key (EncryptedCharField)
    - preferred_model (CharField with choices)
  - Create and run migrations
  - Add user field to Job model (ForeignKey to User, nullable initially for backward compatibility)
  - Add user field to ProcessRun model (ForeignKey to User)
  - Create data migration to assign existing records to a default admin user

- [ ] **3. Create Authentication Serializers and Views** (Complexity: 4)
  - Create UserSerializer for user registration and profile
  - Create LoginSerializer for authentication
  - Create PasswordChangeSerializer
  - Implement RegisterView with user creation
  - Implement LoginView with JWT token generation
  - Implement LogoutView with token blacklisting (optional)
  - Implement ProfileView for retrieving/updating user profile
  - Implement ChangePasswordView

- [ ] **4. Add Authentication URLs** (Complexity: 2)
  - Create backend/ats_app/urls.py file
  - Add URL patterns:
    - POST /api/auth/register/
    - POST /api/auth/login/
    - POST /api/auth/logout/
    - GET/PUT /api/auth/profile/
    - POST /api/auth/change-password/
  - Update backend/ats_project/urls.py to include auth routes
